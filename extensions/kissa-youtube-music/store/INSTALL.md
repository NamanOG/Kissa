# Share YouTube Music from your browser with Kissa

Kissa follows Apple Music, Spotify and other Windows players on its own. YouTube Music
in a browser needs one small, free add-on, because Windows cannot tell which website a tab
is playing.

## You need

- Kissa for Windows (free, Microsoft Store), version 4.4.0 or later.
- Google Chrome or Microsoft Edge, with YouTube Music at music.youtube.com.

## 1. Turn it on in Kissa

Open Kissa → **Settings** → **System** → **Share on Discord**, and turn on **Also share YouTube Music**.
(Discord sharing itself must be on too; Kissa asks before turning it on.)

## 2. Add the browser add-on

Kissa shows a button for your browser:

- **Chrome:** Chrome Web Store → "Kissa for YouTube Music" → **Add to Chrome**.
- **Edge:** Edge Add-ons → "Kissa for YouTube Music" → **Get**.

The browser asks to allow it to "read and change your data on music.youtube.com" and to talk
to "127.0.0.1" (that is your own PC). That is all it can reach.

Tip: pin it. Click the puzzle-piece icon in the toolbar and pin "Kissa for YouTube Music".

## 3. Pair it

1. In Kissa, press **Show pairing code**. A six-digit code appears for two minutes.
2. Click the Kissa icon in your browser's toolbar, type the code and press **Pair**.
3. Kissa says **Paired**. You only do this once per browser.

## 4. Play

Play something on music.youtube.com. Kissa shows "Connected", and your Discord profile shows
the song, artist, cover and time. Pause, and the card shows paused; close the tab, and it
clears within a few seconds. Ads and ordinary YouTube are never shared.

## Stop or undo

- Turn off **Also share YouTube Music** in Kissa to stop at once.
- **Forget add-on** in Kissa, or **Unpair** in the add-on, removes the pairing.
- Remove the add-on from your browser's extensions page at any time.

## If something does not work

| You see | Try |
| :--- | :--- |
| "Kissa is not reachable" in the add-on | Open Kissa and make sure "Also share YouTube Music" is on. |
| "Press Show pairing code first" | Press it in Kissa, then enter the new code within two minutes. |
| "That code did not match" | Check the six digits; after five wrong tries, start a new code. |
| Paired, but Kissa says "Waiting" | Make sure the song is playing in a music.youtube.com tab (not youtube.com). |
| Nothing on Discord | Discord's desktop app must be open, with activity sharing allowed in Discord's settings. |
