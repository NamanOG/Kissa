# Kissa Website — Product Media Assets

This directory contains screenshots and demonstration media used throughout the official Kissa marketing website.

Location: `apps/website/public/product/`

The website automatically resolves media files placed in this directory matching the supported filenames below.

---

## Product Screenshots

| Filename | Used In | Description |
| --- | --- | --- |
| `product-main-window.png` | Hero / Product Modes | Primary windowed desktop interface with active record, tonearm tracking, and track information. |
| `product-fullscreen.png` | Product Modes | Fullscreen listening experience with centered vinyl turntable and atmospheric lighting. |
| `product-fullscreen-lyrics.png` | Product Modes | Fullscreen player with real-time synchronized lyrics and active verse highlighting. |
| `product-screensaver.png` | Product Modes | Living screensaver display with rotating record, clock, and ambient atmosphere. |
| `product-screensaver-lyrics.png` | Product Modes | Screensaver experience with synchronized lyrics flowing in time with the record. |
| `product-record-shelf.png` | Product Modes | Archival crate browsing view displaying collected albums and jacket artwork. |

### Image Specifications

- Resolution: 1920 × 1080 (16:9 aspect ratio) or 1920 × 1200 (16:10 for main window).
- Format: PNG.
- Source: Direct captures from Kissa running on Windows 10/11.

## Fallback Behavior

When a product asset is not present, the website displays an accessible fallback state with an interface preview badge and description rather than a broken image.
